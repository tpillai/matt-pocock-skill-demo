Practice project

Three exercises are planted in the code

Run the scenario and you'll see all three problems in the output.

mvn -q compile exec:java
Asha borrowed Effective Java, due 2026-10-15 Ravi could not borrow it: Book already on loan: 978-0134685991 ← A Asha returned it on the due date. Fee charged: $0.25 ← B Ravi's Clean Code is now due 2027-10-01 (nobody stopped that) ← C
Exercise A · Phases 1–2

Missing feature: holds

Ravi can't queue for a borrowed book. Build holds: a member places a hold on a borrowed book; on return, the first holder gets it. Let the grill ask how long a hold is kept, whether you can hold a book that's on the shelf, and whether it counts toward the 3-loan limit. Don't answer in advance.

Exercise B · Phase 3

Seeded bug: due-date fee

Returning on the due date costs $0.25. Tests pass because one only checks the fee is positive. Don't say where the bug is.
